# RoboKart FMS

This is the FMS application for RoboKart, which primarily handles Controller <-> Robot mappings, race management, and control overrides.

## How To Run

- Clone this repository to the FMS computer, and ensure the correct Python version is installed (as seen in pyproject.toml).
- Use UV or manually install all dependencies in a virtual environment.
- Run FMS.py using the virtual environment Python binary
- The FMS interface will open in a new browser tab/window.
> [!TIP]
> When closing the FMS, use the Shutdown button on the interface, which will properly shut down the program.
